## 🎬 Demo live

Hyrja është **mock demonstrimi** — zgjidh rolin (nuk ka kredenciale reale):
- **👤 Pacient** — rezervo takim (specializim → mjek → datë/orë), shiko takimet
- **🩺 Mjek** — takimet e ditës, detajet e pacientit me një klik
- **🛠️ Admin** — dashboard me statistika, kërkim dhe menaxhim mjekësh/pacientësh

## 🐘 Origjinali PHP

`original/` përmban kopje të paprekura të **të 85 file-ve .php** (admin, doctor, patient),

imazhe, fonte) janë përjashtuar nga paneli i kodit për ta mbajtur të lexueshëm —
